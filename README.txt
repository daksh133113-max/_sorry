I'M SORRY — APOLOGY WEBSITE

Four sequential screens: intro, song player, photo memories, and final apology letter.

PERSONALIZE:
1. Add your MP3 song at music/song.mp3.
2. Add your photos in photos/ named photo-1.jpg, photo-2.jpg, and photo-3.jpg.
3. Edit the final paragraph in index.html inside the letter-body section.

RUN LOCALLY: Open index.html in a browser.
PUBLISH: Upload index.html, style.css, script.js, photos/, and music/ to the root of your GitHub repository. Enable GitHub Pages from main / (root).

The project does not include a copyrighted song or your personal photos. Add files you have permission to use.
